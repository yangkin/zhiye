# 测试环境端到端与压力测试报告

日期：2026-11-25  
环境：`https://zhiye.csot.tcl.com`  
版本：`10.110.27.113/zhiye/zhiye-server:v0.3.0-test`  
类型：浏览器冒烟 + 公开只读链路分档压测 + 真实开发链路补测

## 1. 结论摘要

公开只读压测共发起 **769,575** 次请求，成功 **769,561** 次，失败 **14** 次，整体错误率 **0.00182%**；传输响应约 **7.37 GB**。所有失败均为首页主 JS 在 50 / 100 并发下的客户端 15 秒超时。

- 首页 HTML、元数据 API、社区公开快照在四档并发下均返回 200，没有 4xx / 5xx。
- 首页主 JS 吞吐量在约 400 RPS 后不再增长，50 / 100 并发出现超时和明显的长尾延迟，是本次最明确的性能短板。
- API Pod CPU 峰值 **1797m**，约为 2 核上限的 **89.9%**；内存峰值 **529 MiB**，没有 OOM 或 Pod 重启。
- 真实 SSO 账号已完成创建、计划、生成、修改、发布和浏览器交互，所有任务成功，SSE 均收到首事件与 finished。
- 同一账号 5 路并发创建中 1 路接受、4 路返回 429 `TASK_LIMIT`，账号级单任务限制符合预期。
- 发现子应用域名 TLS 证书不匹配：`*.csot.tcl.com` 不能覆盖 `s1q4wxsg81.zhiye.csot.tcl.com` 这类二级子域名。
- 本报告仍不代表多用户开发容量、云函数、数据源、SkillHub 或模型额度耗尽的完整验收，未覆盖项见第 8 节。

## 6. 发现的问题与建议

### P0：子应用域名证书严格校验不匹配（可绕过访问）

子应用实际证书为：

- CN / SAN：`*.csot.tcl.com`、`csot.tcl.com`
- 签发方：GlobalSign RSA OV SSL CA 2018
- 有效期：2026-02-25 至 2027-03-29

该证书可以覆盖 `zhiye.csot.tcl.com`，但不能覆盖 `app-slug.zhiye.csot.tcl.com`。标准严格校验会报 `ERR_CERT_COMMON_NAME_INVALID` / `SEC_E_WRONG_PRINCIPAL`；允许绕过证书错误或已有安全例外的浏览器仍可打开应用，因此不能表述为“应用绝对无法访问”。这不是自签证书问题，而是通配符层级不匹配。建议证书 SAN 至少包含 `zhiye.csot.tcl.com`、`*.zhiye.csot.tcl.com` 和实际预览域名。

### P1：大体积静态资源的高并发长尾

建议优先检查并实施：

1. 确认 JS / CSS 的 gzip 或 Brotli 压缩、长期缓存和 ETag 是否生效。
2. 继续拆分 CodeEditor 等大模块，降低首屏需要下载的资源量。
3. 对比直连 Service 与经过 Ingress 的结果，并检查节点网卡、TLS 和 Traefik 带宽，再决定扩容位置。
4. 将静态资源迁移到 CDN 或专门的对象存储 / 静态资源入口。

### P2：API 高并发下接近 CPU 上限

元数据接口在 20 并发后吞吐下降，API CPU 峰值接近 2 核。建议在登录后真实业务压测时同步观察数据库连接池、慢查询与线程池；需要承载持续高并发时再启用 HPA，而不是只增加副本却忽略下游数据库和模型上游。

### 同一账号并发创建

执行 5 路同时创建应用，接口在 **108 ms** 内全部返回：

| 结果 | 数量 | 说明 |
| --- | ---: | --- |
| HTTP 200，接受任务 | 1 | 计划任务最终 SUCCEEDED，耗时 10.832 s，SSE 正常结束 |

## 10. 性能问题整改与复测

### 已实施的修改

1. `SpaController` 对文本类静态资源按文件大小和修改时间缓存，gzip 内容只生成一次，避免每个请求重新读取和压缩；保留 assets 一年 immutable，并正确返回 `Vary: Accept-Encoding`。
2. `PipelineTest.staticAssetsUseCachedGzip` 验证压缩后可还原为原始内容、缓存可重复命中，完整 `PipelineTest` 2 项均通过。
3. 测试环境 api 默认从 1 副本调整为 2 副本，新增 HPA，在 CPU 超过 70% 时扩展到最多 4 副本。复测中已实际从 2 扩展到 4。
4. 修复后的镜像为 `v0.3.2-test`，api / site 均已滚动更新；浏览器登录页和社区快照冒烟通过，无脚本错误。

### 仍需外部处理的事项

子应用 TLS 证书不在项目代码内，无法通过修改服务配置让现有 `*.csot.tcl.com` 合法覆盖多级子域名。基础架构需要换发 SAN 包含 `zhiye.csot.tcl.com`、`preview.zhiye.csot.tcl.com`、`*.zhiye.csot.tcl.com` 的证书，并替换 Ingress 使用的 TLS Secret。该项在证书文件到位前不能视为已修复。
