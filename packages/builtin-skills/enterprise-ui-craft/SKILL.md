# 企业级 UI/UX/UE 与反 AI 味视觉规范

## 1. 核心审美原则（拒绝“廉价 AI 模板味”）
- **杜绝花哨渐变堆砌**：避免整页暗紫霓虹、彩虹渐变按钮、无意义 3D 发光卡片与大段装饰性营销 Hero；管理台/看板首屏直接呈现核心业务数据与操作。
- **全宽流式画布**：主工作区使用 `w-full` 与合理内边距（`px-5 lg:px-7`），**禁止**套用 `max-w-5xl / max-w-6xl / max-w-7xl mx-auto` 导致 1440px～4K 屏幕两侧出现大片留白。
- ** 克制而清晰的色彩系统**：
  - 90% 中性画布（底色 `#f7f6fb` / `#f8fafc`，卡片纯白 `#ffffff`，细边框 `1px solid #e6e3f0`）；
  - 8% 清晰文字层级（主墨色 `#1b162c`、正文 `#3c3550`、辅助 `#6c667d`、占位 `#9a93ac`）；
  - 2% 主强调色 + 严格语义色（正常/达标绿 `#15803d`、预警琥珀 `#b45309`、严重异常红 `#dc2626`、进行中蓝 `#2563eb`）。
- **数字排版**：所有 KPI、表格数值、百分比、金额、时间戳强制启用 `tabular-nums`（`font-variant-numeric: tabular-nums`），确保列纵向对齐、动态刷新不抖动。

## 2. 控件与交互零妥协标准
- **严禁原生 `<select>`**：全部筛选器、状态切换、角色选择器必须使用自研风格化下拉组件（圆角弹层、选中高亮勾、支持 `Esc` 关闭与键盘上下切换），严禁弹出系统深灰原生菜单。
- **输入框与按钮统一规格**：
  - 同一表单/工具栏内的输入框、下拉框与主按钮高度严格一致（如 `36px` 或 `38px`）、圆角一致（`8px`～`10px`）；
  - 所有输入框必须有明确 `hover` 边框变深和柔和聚焦光环（`ring-2 ring-indigo-500/20`），占位符对比度清晰。
- **多列表单绝不错位**：
  - 2 列并排字段的 Label 保持单行，将补充说明（「可选」「加密托管」）拆成同行右侧轻量小徽章，严禁左侧 1 行 Label、右侧折 2 行导致底部输入框高低错位。
- **弹窗与抽屉规范**：
  - 表单弹窗宽度 ≥ `560px`（复杂登记表/详情预览 ≥ `780px`），采用「固定顶栏 + 可滚动正文 + 固定浅底 Footer（右对齐：次按钮 + 主按钮）」三段式结构；
  - 列表项详情优先用右侧抽屉（Drawer，`480px～640px`），不破坏当前筛选上下文和滚动位置；
  - 严禁框套框（弹窗里再套带边框滚动小盒子）。

## 3. 数据表格与状态反馈
- **高信息密度表格**：表头浅底加粗可固定（`sticky top-0`），文本左对齐、数字右对齐、状态胶囊与操作列紧凑对齐；长 ID/工单号使用等宽字体（`font-mono`）+ 一键复制或省略提示。
- **完整四态**：每个数据区块必须具备「骨架屏加载态 / 真实数据态 / 友好空态（含明确引导动作）/ 错误可重试态」，杜绝白屏、死按钮或无响应点击。
- **即时反馈**：新增、编辑、状态流转、导入导出操作完成后必须给出 Toast 反馈，危险操作（删除/下线/重置）需有二次确认。
