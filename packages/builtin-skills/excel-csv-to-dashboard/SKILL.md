# Excel / CSV 一键生成交互式分析看板规范

## 1. 第一原则：绝不使用假数据替代用户上传的真实表格
当 `public/assets/` 下存在用户上传的 `.xlsx` 或 `.csv` 文件时：
1. **必须读取真实全量数据**：严禁只看 Prompt 里的前几行示例就手写 10 条假数组！
2. **推荐“构建期预解析 + 运行期支持重传刷新”双保险架构**：
   - **构建期预解析（首屏 0ms 秒开）**：在沙箱里直接写一个短 Node 脚本（利用已安装的 `read-excel-file/node`、`xlsx` 或 `papaparse`）把 `public/assets/<文件名>` 全量解析为结构化 JSON（如 `src/data/dataset.json`，超 5000 行时同步输出聚合汇总 + 明细分页切片），确保打包后的静态站点零请求延迟、不依赖浏览器再解析大文件。
   - **运行期热替换（持续可用）**：在看板顶栏提供「导入新 Excel / CSV 更新看板」按钮与拖拽区，浏览器内用 `read-excel-file/browser` + `papaparse` 解析用户后续拖入的新表，**所有 KPI、图表、筛选器与明细表立即按新数据重算刷新**，并支持一键恢复初始内置数据。

## 2. 智能数据剖析与看板自动建模
解析表格后按列特征自动完成以下映射：
- **时间列**（日期/月份/周次/班次）→ 折线图 / 面积图趋势 + 环比/同比计算 + 顶部时间区间筛选器；
- **维度列**（厂区/部门/产线/产品线/状态/负责人，去重值 ≤ 30）→ 全局下拉筛选胶囊 + 分组柱状图 / 堆叠柱状图 / 占比环形图 + **点击图表元素反向联动全局筛选**；
- **数值指标列**（产量/金额/良率/工时/缺陷数/成本）→ 顶部 4～6 个等宽数字 KPI 卡（总量、均值、达成率/极值、环比变化）+ TOP N 排行榜；
- **自动异常洞察条**：基于真实数据实时计算 Top 贡献项、最大值/最小值、低于均值或超阈值异常项，生成 2～3 句数据驱动的动态结论（严禁写死静态结论文字，筛选条件变化时结论必须跟着实时重算）。

## 3. 交互闭环与导出
- **联动与下钻**：点击任意柱图/饼图/维度标签可将条件同步写入筛选条（展示可关闭的筛选芯片 + 一键重置），下方明细表同步过滤；
- **明细表与报表导出**：提供搜索、列排序、分页，并支持用 `write-excel-file/browser` 将当前筛选结果一键导出为标准 `.xlsx` 报表（保留中文列名与数值格式）；
- **多 Sheet 支持**：若上传的 `.xlsx` 包含多个 Sheet，提供顶部 Sheet 切换 Tab 或将主表与明细表做关联分析。

## 4. 编码前必检清单
- 处理中文表头前后空格、BOM 头（`\uFEFF`）、千分位逗号（`"1,234.5"`）、百分号（`"98.6%"`）和 Excel 序列日期数字；
- 校验 `dataset.json` 非空且行数与原始上传文件一致，避免静默解析失败。
