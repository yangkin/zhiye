# 半导体与智能制造：良率、SPC 与 8D 闭环规范

## 1. 制造领域标准层级与术语
- **标准钻取层级**：`厂区 (Fab: T1/T2/T6/T7/T9/T11)` → `产品线 (TV/IT/Mobile/Auto)` → `工序 (Array / Cell / CF / Module / Litho / Etch / CVD)` → `机台与腔室 (EQP / Chamber)` → `批次 / 玻璃 / 晶圆 (Lot / Glass / Wafer)`。
- **核心指标定义（严格区分比率与绝对值）**：
  - **直通良率 (FPY)** / **综合良率 (Yield)**：保留 2 位小数（如 `98.42%`），配目标线（Target，如 `98.00%`）与红线告警值（Alarm，如 `97.20%`）；
  - **OEE** = `时间稼动率 × 性能稼动率 × 良品率`，支持拆解三因子损失瀑布图；
  - **Defect Density / DPU / DPPM**：配合帕累托图（柱状缺陷数 + 折线累计占比%，标出 80% 关键少数分界线）。

## 2. SPC 控制图与工程判异实现
不要只画一条普通折线假装 SPC！真正的 SPC 视图必须包含：
- **控制线绘制**：使用 Recharts `ReferenceLine` 清晰标出 `USL / LSL`（规格上下限，虚线红）、`UCL / LCL`（控制上下限 `μ ± 3σ`，虚线橙）与 `CL`（中心线 `μ`，实线灰）；
- **真实过程能力指数**：根据当前筛选样本实时计算 `μ`、`σ`、`Cp = (USL - LSL) / (6σ)`、`Cpk = min((USL - μ)/(3σ), (μ - LSL)/(3σ))`，并按行业分级着色（`Cpk ≥ 1.67` 优、`1.33～1.67` 良、`1.00～1.33` 警戒、`< 1.00` 能力不足）；
- **Western Electric 自动判异标红**：自动高亮触发以下规则的点位并在 Tooltip 显示触发原因：
  - Rule 1：单点超出 `UCL / LCL`（3σ）；
  - Rule 2：连续 7 点落在中心线同侧；
  - Rule 3：连续 6 点单调递增或递减。

## 3. 8D 质量异常闭环工作流
- **严谨状态机**：`新建告警 (OPEN)` → `D1-D3 应急围堵 (CONTAINMENT)` → `D4 根因分析 (RCA)` → `D5-D6 永久对策与验证 (CAPA)` → `D7-D8 标准化与结案 (CLOSED)`，禁止非法跨级或回退，每次流转强制填写处理人与说明并写入时间轴。
- **SLA 超期预警**：按严重等级（`S1 停线红警 4h` / `S2 良率波动 24h` / `S3 一般偏差 72h`）实时倒计时与超期高亮，支持一键推送飞书告警卡片（启用飞书连接器时）。
- **关联下钻**：点击良率骤降点或 SPC 越界点可直接查看同班次受影响 Lot 列表，并一键带入机台/批次上下文发起 8D 异常单。
