# 无页面 Python / Node.js 自动化脚本工程规范

## 1. 适用场景与产出原则
当用户明确需要**纯 Python 或 Node.js 脚本**（数据清洗、多表对账、Excel/CSV 批量合并、日志解析、自动化汇总报告、飞书群定时播报脚本等，不需要前端页面）时：
- **严禁多余生成前端工程**：不要创建无用的 Vite/React/HTML 页面，保持项目精简干净，聚焦可运行脚本、清晰 `README.md` 与示例数据。
- **统一入口与参数**：
  - Python 入口推荐 `main.py`（`argparse` 支持 `--input`、`--output`、`--format`、`--dry-run` 等参数，带 `--help` 中文说明）；
  - Node.js 入口推荐 `index.mjs`（使用 `node:util` `parseArgs` 零额外依赖解析参数）；
  - 无参数直接运行时自动加载内置样例数据或 `data/` 下默认文件，确保用户在工作台点击「立即运行」零配置即可跑通并看到完整产出！

## 2. 健壮数据处理与产物输出
- **文件编码与容错**：读取 CSV/TXT 时兼容 UTF-8 BOM（`utf-8-sig`）及 GBK 回退；空值、千分位数字、百分号、异常行要安全清洗并输出**数据质量校验摘要**（总行数、有效行数、跳过异常行数及原因）。
- **结构化产物落地 `output/`**：
  - 每次运行将生成的汇总表（`.csv` / `.xlsx`）、分析报告（`.md` / `.json`）统一写入项目根目录下的 `output/` 目录（确保 `os.makedirs("output", exist_ok=True)`），平台会自动扫描 `output/` 并展示可在线预览与一键下载的产物列表；
  - 控制台 `stdout` 输出简洁可读的执行进度、关键指标汇总表与产物路径，错误信息输出至 `stderr` 并返回非零退出码。

## 3. 安全与外部集成纪律
- 不在代码里硬编码任何密钥、Token 或内网密码，一律从环境变量读取（缺失时给出清晰中文提示并优雅降级演示）；
- 若需要推送飞书卡片或读写飞书多维表格，优先读取平台注入的 `ZHIYE_CONNECTOR_API` 与 `ZHIYE_CONNECTOR_TOKEN` 环境变量，零密钥免配直连；
- 自检要求：交付前必须在沙箱内实际执行入口脚本（默认参数 + `--help`）验证退出码为 `0` 且 `output/` 产物非空、内容准确。
